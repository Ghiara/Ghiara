I build embodied agents that can **continually acquire, reuse, and compose knowledge** for complex robotic tasks. My work brings together lifelong learning, reinforcement learning, language-guided reasoning, and robot manipulation.

<details>
  <summary><strong>Project descriptions and links</strong></summary>
  <br>

- [LEGION](https://github.com/Ghiara/LEGION) — Lifelong reinforcement learning with a Bayesian non-parametric knowledge space and language embeddings.
- [DAHLIA](https://github.com/Ghiara/DAHLIA) — Progressive in-context code generation and episodic visual feedback for long-horizon manipulation.
- [HELIOS](https://github.com/Ghiara/HELIOS) — Hierarchical reinforcement learning with adaptive Bayesian non-parametric skill priors.
- [LYRA](https://github.com/Ghiara/LYRA) — Human-guided lifelong code generation for reusable and extensible robotic skills.
- [ReMAP](https://github.com/Ghiara/ReMAP) — Transfer of reusable meta-knowledge across agents with different embodiments.

</details>
